# Japanese Gravure

[Japanese Gravure](https://japanese-gravure.github.io/) is an independent, non-commercial bilingual reference project exploring the history and aesthetics of Japanese gravure as portrait photography and visual culture.

The site traces the subject from gravure printing, early photographic magazines, ukiyo-e, bromides, and prewar star culture to modern magazine gravure, photobooks, idols, moving-image works, production practices, and fan relationships.

It approaches gravure as a collaborative form of portraiture shaped by performers, photographers, editors, stylists, agencies, publishers, and audiences.
